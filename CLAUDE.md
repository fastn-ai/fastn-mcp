# fastn-mcp

This repository is documentation only. It points to the Fastn MCP Gateway (Fastn Connect): endpoint `https://mcp.fastn.dev/<org>`, docs at https://connect.fastn.dev/docs. The docs at connect.fastn.dev are the source of truth; update the README from them, never the other way round.

Do not recommend `https://mcp.live.fastn.ai`, `pip install fastn-mcp-server`, or the `find_tools` / `execute_tool` / flow tools: they are the retired v1 server, kept on the `v1` branch for reference only.
